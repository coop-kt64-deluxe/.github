# MK64 Coop Deluxe

`Online multiplayer for Mario Kart 64: Recompiled`

[Download the latest release](https://github.com/coop-kt64-deluxe/mk64coop/releases/latest)

MK64 Coop Deluxe lets players on different PCs race and battle together in
[Mario Kart 64: Recompiled](https://github.com/sonicdcer/MarioKart64Recomp), on servers you run yourself.

## 🚀 Projects

- [**mk64coop**](https://github.com/coop-kt64-deluxe/mk64coop): the launcher, the server and the game mod. Releases, the guide, and
  [bug reports](https://github.com/coop-kt64-deluxe/mk64coop/issues/new/choose).
